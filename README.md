# 💌 Open When Letters

a collection of “open when” letters for the moments you need them most 🌿✨

---

## 🌙 about this project

this project is a small digital space made with love,  
created to feel like a warm place you can return to anytime you need comfort 💚

it contains a collection of “open when” letters  
written for different emotional moments—  
when you're happy, tired, sad, overwhelmed, or just missing someone.

each letter is meant to feel like a soft reminder that you are not alone.

---

## 💌 purpose

life can feel heavy sometimes.

this project exists to remind you that:

- you are doing better than you think 🌿  
- your feelings are valid 💔  
- rest is allowed 😴  
- joy is still coming your way 🎉  
- you are deeply valued 💚  

even on the quietest days, you are not alone.

---

## ✨ features

- 🔐 password-protected access

- 🌿 soft aesthetic design  
- 💚 floating heart animations
